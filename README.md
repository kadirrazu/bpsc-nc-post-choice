# Laravel Tabler Starter

Reusable Laravel admin starter with Fortify authentication,
Tabler UI, designations, roles and user management.

## Features

- Laravel
- Laravel Fortify
- Blade and Vite
- Tabler admin template
- Login and logout
- Protected dashboard
- User CRUD
- User designations
- Basic user roles
- Active/inactive user status

## Installation

1. Clone the repository
2. Run `composer install`
3. Run `npm install`
4. Copy `.env.example` to `.env`
5. Run `php artisan key:generate`
6. Configure the database
7. Run `php artisan migrate --seed`
8. Run `npm run dev`
9. Run `php artisan serve`
